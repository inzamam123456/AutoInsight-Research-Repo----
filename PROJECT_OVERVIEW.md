# AutoInsight — Project Overview

## Official title
AutoInsight: An Automated Prompt-Driven Data Analysis and Dashboard Generation System with Traceable Insights

**Domain:** AI, Data Analytics & Explainable AI  
**Planned platform:** Python, NLP/LLMs, statistical analysis and Tableau.

## Problem context
The project addresses four connected challenges:
1. **Lack of clean and structured data:** raw spreadsheet data often needs preparation before analysis.
2. **Lack of domain knowledge:** choosing suitable analyses and visualizations can require technical knowledge.
3. **Interpretation of visualization:** dashboards can present results without sufficiently explaining their meaning.
4. **Visualization history and verification:** users need a way to review how visual outputs and findings were produced.

## Proposed system
A user provides an Excel file and a natural-language prompt. The system is intended to detect column types, prepare data while recording transformations, interpret the prompt, perform suitable statistical/trend/correlation/forecasting/causal analyses, generate Tableau dashboards, produce ranked plain-English insights, attach confidence context, flag fairness considerations, link findings to source rows or formulas, maintain visualization history and support dataset-grounded follow-up Q&A.

## Research-stage boundary
This document describes the approved project direction and proposed capabilities. It does not assert that the system has been implemented, tested or achieved any performance target.
